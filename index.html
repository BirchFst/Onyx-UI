发布说明 v1.5.0

本次补齐了代码容器，并把移动端的文本选中改成「按需开启」—— 手机上长按不再动不动就选中一段文字。

页面内容区。导航栏高度由 --ox-navbar-h 控制。

导航按钮状态

默认与当前之间只差一条下划线 —— 它从中间向两侧展开，文字颜色同步加深； 正方形图标按钮没有文字可划线，依旧使用浅色底。

默认 悬停 当前 禁用 带图标 --pill
App shell · 导航栏不进滚动区

经典滚动条属于什么在滚动：整页滚动时它属于视口，会被画在窗口的整个右边缘上， 连导航栏那一行也一起压住 —— 导航栏的盒子止于 clientWidth，看起来就比窗口窄了一截， 而那条缝是视口的一部分，导航栏上的 CSS 改不了它。
把滚动交给一个从导航栏下方开始的内层容器（本页就是这么做的），轨道便从导航栏下方开始： <body class="ox-shell"> + <div class="ox-shell__body">…</div>。 .ox-shell 会把 --ox-top-inset 置为 0， 于是 .ox-sidebar--sticky 与锚点偏移自动改成从容器顶部量，两种布局下的视觉位置完全一致。

Toast 通知

浮层通知确实需要 JS —— 由可选扩展 onyx-toast.js 提供

OnyxUI.toast()

点下面的按钮，通知会从右上角滑入。鼠标移到某条通知上，倒计时与进度条会一起暂停。

语义
进阶用法
静态渲染（不需要 JS）

把下面这段标记直接写进页面，就是一个静态通知卡片；布局、配色、关闭按钮全部来自 CSS。

部署完成

release/2.4 已上线 3 个区域。

查看代码 
<!-- 1 · 引入：核心 + toast 扩展（不需要构建） -->
<link rel="stylesheet" href="static/onyx-ui.min.css">
<link rel="stylesheet" href="static/onyx-toast.min.css">

<script src="static/onyx-ui.min.js"></script>
<script src="static/onyx-toast.min.js"></script>

<!-- 2 · 调用 -->
<script>
  // 字符串简写
  OnyxUI.toast('已保存');

  // 完整写法
  OnyxUI.toast({
    variant: 'success',            // neutral | info | success | warning | danger
    title: '部署完成',
    description: 'release/2.4 已上线 3 个区域。',
    position: 'top-right',         // top|bottom × left|center|right
    duration: 4200,                // 毫秒；0 = 常驻，鼠标悬停自动暂停
    dismissible: true,             // 显示关闭按钮
    action: { label: '撤销', onClick: function () {}, closeOnClick: true },
    onClose: function (node) {}    // 关闭后回调
  });

  // 快捷方法
  OnyxUI.toast.success('已保存');
  OnyxUI.toast.info({ title: '提示', description: '…' });
  OnyxUI.toast.warning('磁盘空间不足');
  OnyxUI.toast.danger({ title: '构建失败', description: '2 个用例未通过' });

  // 同一条通知原地更新（进度类场景）
  OnyxUI.toast.info({ id: 'upload', title: '正在上传', description: '0%', duration: 0 });
  OnyxUI.toast.update('upload', { description: '60%' });
  OnyxUI.toast.success({ id: 'upload', title: '上传完成', duration: 3000 });

  // 手动控制
  var node = OnyxUI.toast.success('完成');
  OnyxUI.toast.dismiss(node);        // 关掉指定的一条（也可传字符串 id）
  OnyxUI.toast.clear();              // 关掉全部
  OnyxUI.toast.clear('bottom-right');// 只清某个角落
</script>

API 速查

完整说明（含全部修饰符与变量表）见 README.md

.ox-btn
基础按钮。--primary / --secondary / --ghost / --link / --soft[-tone] / --info / --success / --danger， --xs|-sm|-lg，--pill / --block / --icon / is-loading；禁用请用原生 disabled
.ox-btn-group
拼接式按钮组，内部自动处理首尾圆角与边框合并
.ox-field
表单单元：.ox-label + 控件 + .ox-help[--error|-success]
.ox-input
[aria-invalid] 或 is-error / is-success / is-focus；尺寸 --sm / --lg； 配合 .ox-input-group（前后缀）与 .ox-input-icon
.ox-select
原生下拉的样式化版本，需包在 .ox-select-wrap 内以获得自绘箭头
.ox-choice
勾选与单选，子级 __box 或 __dot
.ox-switch
开关，子级 __track
.ox-segmented
分段控件，当前项用 aria-selected="true"
.ox-dropdown
基于 <details> 的菜单：__menu / __item / __label / __sep / __head / __empty / __caret / __trail， --end / --up / --wide
.ox-navbar
__inner / __brand / __brand-mark / __nav / __link / __link--icon / __actions / __sep， --sticky / --flush / --solid / --bordered
.ox-sidebar
__group / __title / __item / __count / __footer，is-active，--sticky
.ox-card
__header / __heading / __title / __desc / __body / __footer，--interactive / --raised / --float
.ox-avatar
--sm / --lg / --ink / --squircle / --ring / --presence + __presence；.ox-avatar-group
.ox-user
头像 + 名称 + 副标题的横向组合，__body / __name / __meta
.ox-badge
--neutral / --success / --warning / --danger / --info / --purple， --sm / --outline / --pulse + __dot
.ox-alert
--info / --success / --warning / --danger / --solid + __icon / __title / __text
.ox-progress
__bar（宽度用内联 style），--lg / --success / --danger
.ox-skeleton
骨架屏，--text / --circle
.ox-tooltip
气泡提示，文本写在 data-tooltip 属性上。鼠标悬停显示； 触摸设备上由 onyx-ui.js 改为长按显示（触屏没有 hover）
.ox-toast
通知卡片：--neutral / --info / --success / --warning / --danger + __icon / __body / __title / __desc / __actions / __close / __progress； 容器 .ox-toaster[data-position]
OnyxUI.toast
由 onyx-toast.js 提供的通知 API： toast(options|string)、.success/.info/.warning/.danger/.neutral、 .update(id, opts)、.dismiss(node|id)、.clear(position?)
OnyxUI.init
动态插入标记后再扫一遍（下拉菜单 + 代码容器），通常不需要手动调用
OnyxUI.copy
复制文本并返回 Promise；安全上下文走 navigator.clipboard， 否则回退 execCommand（局域网 HTTP 也能用）
.ox-codeblock
代码容器：__bar / __title / __copy。 <pre class="ox-code"> 会被 onyx-code.js 自动包进容器并补上复制按钮； 标题与文案用 data-title / data-copy-label / data-copied-label
